# 100 — 전반 기획 (코어)

> 게임의 룰과 구조를 정의하는 코어 기획 문서. 이 문서의 내용이 우선순위의 기준이다.
> 추가 기획(색상 시스템 등)은 `101_extra_design.md`, 필요 에셋은 `102_required_assets.md`.

## 1. 주제 해석 — 초지일관

"초지일관" = 처음부터 끝까지 일관된 마음가짐.

게임적 해석: **플레이어가 스스로 "뜻"(자기에게 부과하는 이동 제약)을 정하고, 게임이 끝날 때까지 그 뜻을 관철하는 것.**

- 뜻을 지킬수록 이동이 불리해짐 → 뜻을 고집하는 것이 곧 게임의 난이도이자 정체성
- 상대도 자기만의 뜻을 걸고 있다 → 두 플레이어의 뜻이 서로 다른 조건부 도전을 만든다
- 설계 원칙: 뜻은 반드시 **코드가 강제 가능**해야 한다 (자유 입력 불허)

## 2. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 2D 플랫포머 + 드로잉 맵 제작 |
| 인원 | 2인 1매치 (온라인) |
| 진행 방식 | 턴 기반 비동기 흐름 — 그리기/검증/플레이는 각자 로컬, 상태·결과만 동기화 |
| 한 매치 길이 | 목표 10~15분 (방 설정에 따라 변동) |

## 3. 매치 루프 (5단계)

```
① 뜻 선언 → ② 맵 제작 → ③ 검증 플레이 → ④ 맵 교환 플레이 → ⑤ 결과
```

| 단계 | 설명 | 동시성 |
|---|---|---|
| ① 뜻 선언 | 각자 자기 뜻을 선택. 상대의 뜻은 서로 공개됨 | 동시 |
| ② 맵 제작 | 각자 상대를 위한 맵을 그림. 시작점 고정, 골은 유저가 배치 | 동시, 그리기 시간 제한 적용 |
| ③ 검증 플레이 | 제작자가 **상대의 뜻**으로 자기 맵을 클리어. 성공 시 그 기록이 **패타임**이 됨 | 각자 비동기 |
| ④ 맵 교환 플레이 | 각자 **자기 뜻**으로 상대 맵 플레이. 클리어 시간 기록 | 양쪽 제출 완료 후 동시 시작 |
| ⑤ 결과 | 기록 종합 → 랭킹 산출 → 결과 화면 | 동시 |

**매치당 각자 맵 1개씩 제작** (라운드 반복은 추가 기획 — `101_extra_design.md`).

## 4. 뜻(제약) 시스템

### 4.1 규칙

- 뜻은 **미리 정의된 목록**에서 선택 (자유 입력 불허 — 코드가 강제할 수 없기 때문)
- MVP 뜻 목록 3~5종, 아래 우선순위로 선정:

**구현된 뜻 목록 (2026-09-06, `Scripts/Common/Vows.cs` `VowCatalog`)** — 조작 사양(202 1장)의 파라미터를 바꾸는 방식. 새 뜻은 카탈로그에 항목 1개 추가.

| VowId | 뜻 | 내용 | 난이도 | 강제 방식 |
|---|---|---|---|---|
| 1 | 저속 | 이동 속도 ×0.5 | 1 | `MoveSpeed` |
| 2 | 저점프 | 점프 높이 ×0.5 (점프 속도 ×0.71) | 1 | `JumpSpeed` |
| 3 | 고중력 | 상승·하강 중력 ×1.6 | 2 | `RiseGravity`/`FallGravity` |
| 4 | 점프 쿨다운 | 착지 후 1초간 점프 불가 | 2 | `JumpCooldownAfterLanding` |
| 5 | 점프 5회 | 시도당 점프 5회, 리스폰 시 초기화 | 2 | `MaxJumpsPerAttempt` |
| 6 | 공중 제어 금지 | 점프 순간 수평 속도가 착지까지 고정 | 2 | `AirControl=false` |
| 7 | 큰 몸집 | 캐릭터 1.5배 | 2 | `ApplyBodyScale(1.5)` |
| 8 | 미끄러운 발 | 가속 0.5s·감속 0.6s·정지 마찰 0.05 | 3 | `GroundAccelTime`/`GroundDecelTime`/`IdleFriction` |

이전 초안(점프 금지·역이동 금지·대기 금지)은 조작감 분석 결과 불쾌감이 커 보류. 선택 유효성 검사(조합 금지 등)는 미구현.

- 동일한 뜻을 양쪽이 선택해도 무방하다 (제약은 "자기 맵은 어렵게, 상대 맵을 클리어" 양쪽에 작용)
- **선택 방식**: 라운드마다 무작위 후보 `VowCandidateCount`(기본 5)개 중 `VowPickCount`(기본 1)개를 고른다 — 방 설정. "뜻 없음"은 없다. 양쪽 확정 시 서로의 뜻이 교환되고 맵 제작이 시작된다. 에디터 왼쪽에 상대의 뜻이 표시되어 그에 맞춰 맵을 그린다
- 뜻별 보상(점수 가중치)은 코어에 없음 — 추가 기획 `101_extra_design.md` 4장. 보상이 없으면 약한 뜻으로 수렴할 위험이 있다는 점은 인지된 상태

### 4.2 뜻이 걸리는 시점

- 뜻은 **매치 전체**에 적용: 맵 제작은 뜻의 영향 없음, 검증 플레이와 교환 플레이에 적용
- 검증 플레이 시 제작자는 **상대의 뜻**으로 플레이한다 (자기 뜻 아님)
- 교환 플레이에서는 **자기 뜻**으로 상대 맵을 플레이한다

## 5. 맵 제작 룰

| 항목 | 룰 |
|---|---|
| 시작점 | 고정 (맵 왼쪽 하단 — 정확 좌표는 `203_map_editor.md`) |
| 기본 경계 | **바닥과 시작점 쪽(왼쪽) 벽**은 고정 콜라이더로 항상 존재. **천장과 오른쪽은 개방** — 경계 밖으로 나가면 낙하 판정 → 자동 리스폰 (7.3) |
| 골 | **맵 디자이너가 직접 배치** — 1개만, **필수**. 자동 배치 없음 (노랑 골 존 — 색상 시스템 도입 전까지는 "골 배치 버튼") |
| 그리기 | 펜으로 선을 그리면 선이 물리 벽이 됨 (면 채우기는 스코프 아웃) |
| 보조 기능 | 실행취소(마지막 스트로크 삭제), 전체 지우기 |
| 제한 | 맵 크기 고정, 스트로크 수/길이 상한 (수치는 `203_map_editor.md`) |
| 시간 | 그리기 시간 제한: 방 설정 (2/5/10분, 기본 5분). 만료 시 그리기 종료 → 골 미배치면 **골 배치만 허용되는 상태**로 전환, 배치 즉시 검증 진입 (⚠ 확인 필요) |
| 제출 조건 | 골 배치 + 검증 클리어 완료 시에만 제출 가능 |

## 6. 검증 룰

- 제작자는 자기 맵을 **상대의 뜻**으로 플레이해 클리어 가능함을 증명해야 함
- 검증은 **시도 무제한**이지만 1회 검증 플레이에 **플레이 시간 제한**(방 설정 7.1, 검증·교환 공용)이 걸린다. 검증 시간은 랭킹에 불산입, 클리어 시간만 패타임으로 기록
- 검증 시간 만료 시 에디터로 복귀 → 맵 수정 후 재검증 (그리기 시간이 이미 만료됐더라도 수정 허용 ⚠ 확인 필요). 재검증마다 검증 타이머는 새로 시작
- **검증 단계 총 상한**: 검증 첫 진입 후 누적 `플레이 시간 제한 × 2`가 지나도 제출하지 못하면 **제출 실패 → 해당 플레이어 패배**로 매치 종료. 상대의 무한 대기 방지용 (⚠ 수치·처리 확인 필요)
- 검증 실패 시 에디터로 복귀 → 맵 수정 후 재검증
- 검증 클리어 시 즉시 제출 확정 — **제출 후 수정 불가**

## 7. 경쟁 시스템

### 7.1 방 설정 (방장이 로비에서 설정, 기본값 코드 고정)

| 설정 | 옵션 | 기본값 |
|---|---|---|
| 패타임 모드 | 끔 / 켬 | 끔 |
| 시도 제한 | 무한 / 3회 / 5회 | 무한 |
| 그리기 시간 제한 | 2분 / 5분 / 10분 | 5분 |
| **플레이 시간 제한** | 2분 / 3분 / 5분 | 3분 (⚠ 수치 제안) |

- 플레이 시간 제한은 **검증 플레이 1회**와 **교환 플레이 전체**에 같은 값이 적용된다. 목적: 게임이 늘어지는 것 방지. 만료 시 처리는 7.3

### 7.2 랭킹 공식

- **기본 (패타임 끔)**: 클리어 시간 직접 비교. 맵 난이도가 곧 전략 — "내 맵으로 상대를 늦춰라"
- **패타임 켬**: `(클리어 시간 ÷ 패타임)` 비율 비교 — 맵 난이도 정규화, 순수 러닝 실력 대결
- 계산식·동점 처리 상세: `206_ranking.md`

### 7.3 패널티

| 상황 | 처리 |
|---|---|
| 경계 밖 낙하 | **자동 리스폰** (시작점). 시도 미소모, 시간은 계속 흐름 (자연 패널티) |
| R키 수동 리스폰 | 시작점 리스폰. **시도 +1**, 뜻 카운터(점프 횟수 등) 초기화, 시간은 계속 흐름. 갇힘 탈출용 — 검증·교환 모두 적용 |
| 시도 제한 소진 | 미클리어 처리 — 기록 = 최악값 (`206_ranking.md` 2.3) |
| 플레이 시간 만료 | 미클리어 처리 — 기록 = 최악값 (`206_ranking.md` 2.3). 검증 모드에서는 에디터 복귀 (6장) |

## 8. 예외 처리 룰

| 상황 | 처리 |
|---|---|
| 상대가 클리어 실패 | 시도 제한 소진 또는 플레이 시간 만료 시 미클리어 처리 (7.3) — 매치는 반드시 종료됨 |
| 검증이 안 되는 맵 | 제작자가 에디터에서 수정 후 재검증. 검증 단계 총 상한 초과 시 제출 실패 → 패배 (6장) |
| 플레이어가 갇힘 | R키 수동 리스폰 (시도 +1) |
| 연결 끊김 | 남은 매치 무효, 즉시 결과 화면으로 종료 (MVP: 재접속 미지원) |
| 동점 | 동점 처리 규칙 따름 — `206_ranking.md` |
| 그리기 시간 만료 | 그리기 종료. 골 미배치면 골 배치만 허용 → 배치 즉시 검증 진입 (5장) |
