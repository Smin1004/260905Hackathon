# 100 — 전반 기획 (코어)

> 게임의 룰과 구조를 정의하는 코어 기획 문서. 이 문서의 내용이 우선순위의 기준이다.
> 추가 기획(색상 시스템 등)은 `101_extra_design.md`, 필요 에셋은 `102_required_assets.md`.

## 1. 주제 해석 — 초지일관

"초지일관" = 처음부터 끝까지 일관된 마음가짐.

게임적 해석: **플레이어가 스스로 "뜻"(자기에게 부과하는 이동 제약)을 정하고, 게임이 끝날 때까지 그 뜻을 관철하는 것.**

- 뜻을 지킬수록 이동이 불리해짐 → 뜻을 고집하는 것이 곧 게임의 난이도이자 정체성
- 상대도 자기만의 뜻을 걸고 있다 → 두 플레이어의 뜻이 서로 다른 조건부 도전을 만든다
- 설계 원칙: 뜻은 반드시 **코드가 강제 가능**해야 한다 (자유 입력 불허)

## 2. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 2D 플랫포머 + 드로잉 맵 제작 |
| 인원 | 2인 1매치 (온라인) |
| 진행 방식 | 턴 기반 비동기 흐름 — 그리기/검증/플레이는 각자 로컬, 상태·결과만 동기화 |
| 한 라운드 길이 | 목표 10~15분 (방 설정에 따라 변동). 같은 방에서 라운드를 반복한다 (3장) |

## 3. 매치 루프 (라운드 반복)

```
방 참가(방 코드)
   ↓
┌→ ① 뜻 선택 → ② 맵 제작 → ③ 검증 플레이(상대 뜻) → ④ 맵 교환 플레이(내 뜻) → ⑤ 결과 ─┐
│                                                                                   ├─ [다음 라운드] ─┘ (같은 방, 뜻 선택부터)
└───────────────────────────────────────────────────────────────────────────────────┴─ [방 나가기] → 로비
```

| 단계 | 설명 | 동시성 |
|---|---|---|
| ① 뜻 선택 | 각자 후보 카드 중 자기 뜻을 선택·확정. **양쪽 확정 시 서로의 뜻이 교환·공개**되고 맵 제작이 시작됨 | 동시 |
| ② 맵 제작 | 각자 상대를 위한 맵을 그림. 시작점 고정, 골은 유저가 배치. 에디터에 상대의 뜻이 표시됨 | 동시, 그리기 시간 제한 적용 |
| ③ 검증 플레이 | 제작자가 **상대의 뜻**으로 자기 맵을 클리어. 성공 시 그 기록이 **패타임**이 됨. 에디터 안에서 진행 (6장) | 각자 비동기 |
| ④ 맵 교환 플레이 | 각자 **자기 뜻**으로 상대 맵 플레이. 클리어 시간 기록 | 양쪽 제출 완료 후 각자 시작 |
| ⑤ 결과 | 기록 종합 → 판정(승/패/무) → 결과 화면. [다음 라운드] 또는 [방 나가기] | 동시 |

- **한 라운드 = 각자 맵 1개.** 결과 화면에서 양쪽이 [다음 라운드]를 누르면 **같은 방(방 코드·방 설정·상대 유지)에서 ① 뜻 선택부터 다시** 시작한다 — 뜻은 라운드마다 다시 고른다. 방을 새로 만들지 않는다
- **[방 나가기]는 어느 화면에서든** 가능 (뜻 선택·에디터·대기·결과) → 로비로 복귀. 총 라운드 수 상한은 없다 — 에디터 HUD 라운드 배지는 라운드 번호만 표시

## 4. 뜻(제약) 시스템

### 4.1 규칙

- 뜻은 **미리 정의된 목록**에서 선택 (자유 입력 불허 — 코드가 강제할 수 없기 때문)
- MVP 뜻 목록 3~5종, 아래 우선순위로 선정:

**구현된 뜻 목록 (2026-09-06, `Scripts/Common/Vows.cs` `VowCatalog`)** — 조작 사양(202 1장)의 파라미터를 바꾸는 방식. 새 뜻은 카탈로그에 항목 1개 추가.

| VowId | 뜻 | 내용 | 난이도 | 강제 방식 |
|---|---|---|---|---|
| 1 | 저속 | 이동 속도 ×0.5 | 1 | `MoveSpeed` |
| 2 | 저점프 | 점프 높이 ×0.5 (점프 속도 ×0.71) | 1 | `JumpSpeed` |
| 3 | 고중력 | 상승·하강 중력 ×1.6 | 2 | `RiseGravity`/`FallGravity` |
| 4 | 점프 쿨다운 | 착지 후 1초간 점프 불가 | 2 | `JumpCooldownAfterLanding` |
| 5 | 점프 5회 | 시도당 점프 5회, 리스폰 시 초기화 | 2 | `MaxJumpsPerAttempt` |
| 6 | 공중 제어 금지 | 점프 순간 수평 속도가 착지까지 고정 | 2 | `AirControl=false` |
| 7 | 큰 몸집 | 캐릭터 1.5배 | 2 | `ApplyBodyScale(1.5)` |
| 8 | 미끄러운 발 | 가속 0.5s·감속 0.6s·정지 마찰 0.05 | 3 | `GroundAccelTime`/`GroundDecelTime`/`IdleFriction` |

이전 초안(점프 금지·역이동 금지·대기 금지)은 조작감 분석 결과 불쾌감이 커 보류. 선택 유효성 검사(조합 금지 등)는 미구현.

- 동일한 뜻을 양쪽이 선택해도 무방하다 (제약은 "자기 맵은 어렵게, 상대 맵을 클리어" 양쪽에 작용)
- **선택 방식**: 라운드마다 무작위 후보 `VowCandidateCount`(기본 5)개 중 `VowPickCount`(기본 1)개를 고른다 — 방 설정. "뜻 없음"은 없다. 양쪽 확정 시 서로의 뜻이 교환되고 맵 제작이 시작된다. 에디터 왼쪽에 상대의 뜻이 표시되어 그에 맞춰 맵을 그린다
- 뜻별 보상(점수 가중치)은 코어에 없음 — 추가 기획 `101_extra_design.md` 4장. 보상이 없으면 약한 뜻으로 수렴할 위험이 있다는 점은 인지된 상태

### 4.2 뜻이 걸리는 시점 (구현됨)

- 뜻은 **그 라운드 전체**에 적용: 맵 제작은 뜻의 영향 없음, 검증 플레이와 교환 플레이에 적용. 다음 라운드에는 새로 고른 뜻이 걸린다
- **검증 플레이 = 상대의 뜻**: 제작자는 상대가 고른 뜻으로 자기 맵을 클리어해야 한다 (에디터가 `MatchData.OpponentVows`를 검증 세션에 적용)
- **교환 플레이 = 자기 뜻**: 자기가 고른 뜻으로 상대 맵을 플레이한다 (Play 씬이 `MatchData.MyVows`를 적용)
- 적용은 플레이어 스폰 직후 1회, 컨트롤러 파라미터를 바꾸는 방식 — 리스폰해도 유지. 카운터형 뜻(점프 5회)은 리스폰 시 초기화

## 5. 맵 제작 룰

| 항목 | 룰 |
|---|---|
| 시작점 | 고정 (맵 왼쪽 하단 — 정확 좌표는 `203_map_editor.md`) |
| 기본 경계 | **바닥과 시작점 쪽(왼쪽) 벽**은 고정 콜라이더로 항상 존재. **천장과 오른쪽은 개방** — 경계 밖으로 나가면 낙하 판정 → 자동 리스폰 (7.3) |
| 골 | **맵 디자이너가 직접 배치** — 1개만, **필수**. 자동 배치 없음 (노랑 골 존 — 색상 시스템 도입 전까지는 "골 배치 버튼") |
| 그리기 | 펜으로 선을 그리면 선이 물리 벽이 됨 (면 채우기는 스코프 아웃) |
| 보조 기능 | 실행취소(마지막 스트로크 삭제), 전체 지우기 |
| 제한 | 맵 크기 고정, 스트로크 수/길이 상한 (수치는 `203_map_editor.md`) |
| 시간 | 그리기 시간 제한: 방 설정 (2/5/10분, 기본 5분). 에디터 HUD 상단 링에 남은 시간 표시. **만료 시 미제출이면 제출 실패 = 그 라운드 패배** — 골 미배치·검증 미완료·검증 플레이 중 어느 경우든 같은 규칙 (6장) |
| 제출 조건 | 골 배치 + 검증 클리어 완료 시에만 제출 가능 |

## 6. 검증 룰

- 제작자는 자기 맵을 **상대의 뜻**으로 플레이해 클리어 가능함을 증명해야 함
- 검증은 **에디터 안에서** 진행한다 — Play 씬 전환 없음 (그리던 상태·실행취소 기록 유지). [검증하기] → 같은 화면에 플레이어가 스폰되어 플레이 → **골 도달 = 검증 성공** → 잠시 후 에디터 복귀. ESC / [에디터로 돌아가기]로 언제든 복귀 (갇힘 탈출·맵 수정)
- 검증은 **시도 무제한**이지만 검증 플레이 1회에 **플레이 시간 제한**(7.1, 검증·교환 공용)이 걸린다. 만료 시 미클리어로 종료 → 잠시 후 에디터 복귀 → 맵 수정 후 재검증 (재검증마다 타이머 새로 시작). 검증에 쓴 시간은 랭킹에 불산입 — 클리어 시간만 **패타임**으로 기록. 그리기 시간(5장)은 검증 중에도 계속 흐르며 검증·완료까지 포함한 상한이다
- 검증 성공 뒤 맵을 수정(그리기·지우기·골 이동·실행취소)하면 검증 무효 → 재검증
- 검증 성공 상태에서만 [완료] 가능. **완료 = 제출 확정** → 상대에게 맵 전송, 에디터 잠금 — **제출 후 수정 불가**
- **그리기 시간 만료 시 미제출 = 제출 실패 = 그 라운드 패배.** 골 미배치·검증 미완료·검증 플레이 중 등 이유를 가리지 않는다. 상대에게 통지되어 양쪽 모두 즉시 결과 화면(승/패)으로 가고, **양쪽이 동시에 실패하면 무승부**. 이미 제출했다면 타이머와 무관. 결과 화면에서 [다음 라운드]로 이어갈 수 있다

## 7. 경쟁 시스템

### 7.1 방 설정 6종 (호스트 값이 참가자에게 전달, 설정 UI 미구현 — 기본값 코드 고정)

| 설정 | 옵션 | 기본값 |
|---|---|---|
| 패타임 모드 | 끔 / 켬 | 끔 |
| 시도 제한 | 무한 / 3회 / 5회 | 무한 |
| 그리기 시간 제한 | 2분 / 5분 / 10분 | 5분 |
| 플레이 시간 제한 | 2분 / 3분 / 5분 | 3분 |
| 뜻 개수 | 라운드마다 각자 고르는 뜻의 수 (1 이상) | 1 |
| 후보 수 | 제시되는 뜻 후보 수 (0 = 전체) | 5 |

- 설정은 `RoomSettings`(`Scripts/Common/MatchData.cs`) 기본값으로 고정되어 있고, 호스트의 값이 접속 시 Hello 메시지로 참가자에게 전달된다 (`205_network.md`). 로비 설정 UI는 미구현 — 폴백 전략(`SUMMARY.md`) 그대로
- 플레이 시간 제한은 **검증 플레이 1회**와 **교환 플레이**에 같은 값이 적용된다 (만료 시 처리는 7.3). 시도 제한은 교환 플레이에만. 목적: 게임이 늘어지는 것 방지

### 7.2 랭킹 공식

- **기본 (패타임 끔)**: 클리어 시간 직접 비교. 맵 난이도가 곧 전략 — "내 맵으로 상대를 늦춰라"
- **패타임 켬**: `(클리어 시간 ÷ 패타임)` 비율 비교 — 맵 난이도 정규화, 순수 러닝 실력 대결
- 계산식·동점 처리 상세: `206_ranking.md`

### 7.3 패널티

| 상황 | 처리 |
|---|---|
| 경계 밖 낙하 | **자동 리스폰** (시작점). 시도 미소모, 시간은 계속 흐름 (자연 패널티) |
| R키 수동 리스폰 | 시작점 리스폰. **시도 +1**, 뜻 카운터(점프 횟수 등) 초기화, 시간은 계속 흐름. 갇힘 탈출용 — 검증·교환 모두 적용 |
| 시도 제한 소진 | 미클리어 처리 — 기록 = 최악값 (`206_ranking.md` 2.3) |
| 플레이 시간 만료 | 교환: 미클리어 처리 — 기록 = 최악값 (`206_ranking.md` 2.3). 검증: 미클리어 → 에디터 복귀 후 재검증 (6장) |
| 기권 | 교환 플레이 중 ESC / [기권] → 미클리어 처리 (시도 제한 소진과 동일) |

## 8. 예외 처리 룰

| 상황 | 처리 |
|---|---|
| 상대가 클리어 실패 | 시도 제한 소진·플레이 시간 만료·기권 시 미클리어 처리 (7.3). 결과는 반드시 전송되므로 라운드는 항상 종료됨 |
| 검증이 안 되는 맵 | 제작자가 에디터에서 수정 후 재검증. 그리기 시간 안에 제출하지 못하면 제출 실패 → 그 라운드 패배 (6장) |
| 플레이어가 갇힘 | R키 수동 리스폰 (시도 +1). 교환 플레이에서는 기권도 가능 |
| 연결 끊김 | 남은 매치 무효 → 즉시 **매치 무효 화면**(사유 표시). 호스트는 [같은 방에서 새 상대 기다리기]로 같은 방 코드에서 새 상대를 받을 수 있다 (라운드 1부터). 그 외에는 [방 나가기] → 로비. 재접속 미지원 |
| 동점 | 동점 처리 규칙 따름 — `206_ranking.md` |
| 그리기 시간 만료 | 미제출 = 제출 실패 = 그 라운드 패배. 양쪽 동시면 무승부 (6장) |
| 플레이 시간 만료 | 교환: 미클리어 처리 (7.3) — 결과가 전송되어 라운드 종료. 검증: 에디터 복귀 (6장) |
