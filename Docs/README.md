## 읽는 순서

**사람 (팀원):**
1. `SUMMARY.md` — 프로젝트 전체 그림
2. `100_game_design.md` — 게임 룰
3. 자기 담당 분야의 200번대 문서
4. `201_common.md` — 공통 규약 (반드시 숙지)

**AI (코딩 에이전트):**
1. `SUMMARY.md` → `100_game_design.md` → `201_common.md` (필독 3종)
2. 이후 담당 기능 문서 (`202`~`206`)
3. `101`, `102`는 스코프 판단용 참고 — 코어가 아님

## 문서 규칙

- 기획 변경 시 해당 문서를 수정하고, 수정 사유를 팀에 공유할 것
- 코어(100)와 추가 기획(101)의 경계 유지 — 코어를 함부로 넓히지 말 것 (개발 시간 15시간 제약)
- 각 문서 하단의 "관련 문서" 링크를 따라가며 정황 파악
- 문서 안의 **⚠ 확인 필요** 표시는 제안 상태의 수치·규칙 — 팀 확인 후 표시를 지울 것
