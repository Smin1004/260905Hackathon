# 204 — UI 구현

> 화면 흐름과 각 화면 명세. 소유: UI/통합 담당 (Boot·Result 씬) + 각 씬 소유자(자기 씬의 UI 배치).
> **공용 UI 킷 방침은 `201_common.md` 4장 — 각자 자체 제작 UI 금지, 킷 프리팹만 사용.**

## 1. 화면 흐름

```
Boot
 └ Lobby ────────────── 방 참가/생성, 방 설정, 뜻 선택
    └ MapEditor ────────── 맵 제작 (검증 진입)
       └ Play(검증 모드) ─── 상대 뜻으로 자기 맵 클리어
          └ MapEditor(제출/대기) → 양쪽 제출 완료 대기
             └ Play(교환 모드) ─ 자기 뜻으로 상대 맵 플레이
                └ Result ──────── 기록 비교, 랭킹
```

- 화면 전환은 Boot FSM이 제어 — UI는 전환 요청만 발행 (`205_network.md` 매치 FSM)
- "양쪽 제출 완료 대기"는 MapEditor 씬 위의 대기 오버레이로 처리 (제출 후 수정 불가 — `100_game_design.md` 6장)

## 2. 화면별 명세

### 2.1 Lobby
| 요소 | 내용 |
|---|---|
| 닉네임 입력 | 간단 텍스트 입력 (기본값: 플레이어N) |
| 방 생성 | 방 설정 4종 노출 (패타임 모드 토글 / 시도 제한 / 그리기 시간 / 플레이 시간) — `100_game_design.md` 7.1 |
| 방 참가 | 방 코드 입력 (6자리) + 참가 버튼 |
| 방 대기 | 참가자 표시, 준비 상태, 방 코드 크게 표시 (복사 버튼) |
| 뜻 선택 | 뜻 후보 카드형 선택 (전체 목록, 또는 6종 이상이면 랜덤 3·5개 후보) + 뜻 설명 텍스트. "뜻 없음" 카드 없음. 상대 뜻은 **양쪽** 선언 완료 후 공개 |
| 시작 | 양쪽 뜻 확정 시 자동 진행 |

### 2.2 MapEditor
| 요소 | 내용 |
|---|---|
| 툴 바 | 펜 / 지우개 / 골 배치 / 실행취소 / 전체 지우기 (`203_map_editor.md` 1장) |
| 굵기 | 얇게 / 보통 / 굵게 3단계 (지우개 반지름도 연동) |
| 색상 | 팔레트 버튼 (StrokePalette SO 항목 수만큼 자동 생성) |
| 통계 | 스트로크 n/60 · 점 수 · 예상 전송 크기 · 골 배치 여부 (하단 바) |
| 그리기 타이머 | 남은 시간 표시 (방 설정) |
| 검증 버튼 | 골 배치 시 활성화 |
| 대기 오버레이 | 검증 클리어 → "상대 대기 중" 표시 |
| 툴팁 | 시작점 고정 안내 ("시작점은 왼쪽 하단 고정입니다"), 골 배치 필수 안내 ("골을 배치해야 검증할 수 있습니다") |

### 2.3 Play (HUD)
| 요소 | 내용 |
|---|---|
| 타이머 | **남은 시간** (플레이 시간 제한 − 경과, 우측 상단). 10초 이하 강조 |
| 뜻 표시 | 현재 적용 뜻 상시 표시 ("현재 뜻: 점프 금지") |
| 시도 표시 | 시도 제한 설정 시 "시도 2/3" 표시. 항상 "R: 리스폰" 안내 노출 |
| 모드 배너 | 검증 모드 / 교환 플레이 모드 구분 표시 |

### 2.4 Result
| 요소 | 내용 |
|---|---|
| 기록 비교 | 내 클리어 시간 vs 상대 클리어 시간 (양쪽 맵 썸네일 겸용) |
| 패타임 | 패타임 모드 ON 시 각 맵 패타임 + 비율 표시 (`206_ranking.md`) |
| 승패 | 랭킹 산출 결과 크게 표시 (동점 포함) |
| 다시 하기 | 같은 방 유지 재시작 — 시간 남을 때만 (없으면 "게임 종료"만) |

## 3. 공용 UI 킷 (통합 담당 제작·배포)

| 컴포넌트 | 스펙 |
|---|---|
| 버튼 프리팹 | 일반/눌림/비활성 3상태 |
| 패널 프리팹 | 9-slice |
| 토글 | 방 설정용 |
| 인풋 필드 | 방 코드/닉네임 |
| 폰트 | 한글 지원 무료 폰트 1종 (`102_required_assets.md` — 기본 폰트 한글 깨짐 주의) |
| 색 팔레트 | 테마 ScriptableObject (`201_common.md` 5장) |

- 해상도: 1920×1080 기준, Canvas Scaler = Scale With Screen Size
- 플레이스홀더 아트로 시작 — 교체는 프리팹/테마만 바꾸면 전체 적용되도록 (`201_common.md` 아트 방침)

### 구현 현황 (2026-09-06)

- **MapEditor HUD** 가 첫 번째 시안 기반 화면: `Prefabs/UI/MapEditorHud.prefab` + 테마 `UI/MapEditorTheme.asset` + 이미지 `Assets/image/` — 상세 `203_map_editor.md` 9장. 네이비 배경·아이보리 종이·초록 강조·코랄 경고 팔레트가 테마 SO 에 있으므로 Lobby/Play/Result 도 같은 색과 `Assets/image` 패널·버튼 스프라이트(9-slice 보더 설정 완료)를 쓰면 통일된다
- 폰트는 아직 `LegacyRuntime.ttf`(OS 한글 폴백). 시안의 둥근 굵은 한글 폰트는 `102_required_assets.md` 대로 무료 폰트 1종을 들여와 프리팹 텍스트에 일괄 지정해야 한다
- Lobby·Play HUD·Result 는 여전히 `RuntimeUI` 플레이스홀더

## 4. 메시지/문구 기준

- 짧고 명확하게. 뜻 설명은 한 줄 (예: "점프 금지 — 발을 떼면 안 됩니다")
- 상태 안내 문구: "상대의 뜻으로 클리어하세요" (검증), "자기 뜻으로 상대 맵 클리어" (교환)
- 오류 안내: 방 코드 틀림 / 연결 끊김 / 시간 만료 시 각각 1문장
